# 要件定義書: 使用報告書 入荷元施設情報 出力機能

## 背景・目的

メーカーは代理店(DVx)経由で施設(病院)へ製品を貸出し、入庫時にAptageでGS1-128バーコードを
読み取って貸出先施設情報を記録している。製品が施設間移動(横持ち)された場合、実際の使用施設と
メーカーが認識する貸出先施設が食い違い、メーカー側でのデータ書き換えが必要になる。

- DURSを廃止し、使用報告機能をWaTシステムに集約する
- 使用報告書に「入荷元施設(最初の貸出先施設)」を出力可能にする
- 将来的にピンクシール運用を廃止する（本要件は第一段階）

## 業務フロー比較

| | As-Is（現状） | To-Be（WaTシステム） |
|---|---|---|
| ① | メーカー→代理店へ施設紐付けで貸出 | 同左 |
| ② | 代理店→施設へ貸出。Aptageで入庫読取・記録 | WaTで入庫処理（GS1-128読取）。最初の貸出先施設が製品(ロット・シリアル)に記録される |
| ③ | 必要に応じ施設間で横持ち | WaT「在庫移動」機能で横持ちを記録 |
| ④ | 施設で使用 | 使用施設で使用実績を入力 |
| ⑤ | DURSに使用実績入力・メール送信 | WaTが入庫・移動履歴を追跡し「最初の入庫施設」を自動判定 |
| ⑥ | 事務員がAptageに取込 | 使用報告書の「入庫先」欄に自動反映（得意先マスタ参照、手入力不要） |
| ⑦ | バーコードキーで在庫消込 | WaTからAptage取込用テキストを出力 |
| ⑧ | — | Aptageで従来通り消込（突合キーはバーコード情報のみ。施設情報は表示用） |

## 要求事項

| No. | 要求 | 理由 |
|---|---|---|
| 1 | 使用報告時に「最初の入荷施設」を自動把握 | メーカーへの貸出先データ書き換え要否判断 |
| 2 | 横持ちが複数回でも常に「最初の入荷施設」がわかる（中間履歴は不要） | 実運用で複数回移動が発生 |
| 3 | 使用報告書に「最初の入庫施設」項目を追加。手入力不要、既存操作のみで自動反映 | 現場の入力負担を増やさない |
| 4 | 上記以外の現行業務は変更しない | 現場オペレーション変更を最小化 |
| 5 | DURS廃止・WaTへ一本化（当面は並行運用可） | 運用効率化。天理よろづ病院から段階移行 |

## 機能要件（開発対象: F-1, F-3, F-4, F-5, F-6／F-2は既存機能で対応可・開発不要）

### 6.1 入庫処理

- **F-1**: 入庫処理時に選択する「製品保管場所」＝そのまま「最初の入庫施設」。新規入力項目なし。
  既存の入庫処理情報を製品(ロット・シリアル)に紐づけて保持する。

### 6.2 在庫移動（横持ち）

- F-2（開発不要）: 「在庫移動」機能でA病院→B病院等の横持ちを記録（既存機能）。
- **F-3**: 横持ちが複数回(A→B→C)発生しても、最初の入庫処理時の「製品保管場所」を上書きせず
  製品に引き継いで保持する。確定仕様: 履歴を遡って検索する方式は不採用、都度引き継ぐ方式。

### 6.3 使用報告・入庫先の自動反映

- **F-4**: 使用報告時、対象製品(ロット・シリアル)の入庫・移動履歴を自動追跡し「最初の入庫施設」を
  自動判定する。手入力・選択操作は不要。入庫記録が見つからない場合は入庫先欄を空欄
  （使用報告自体はブロックしない）。
- **F-5**: 同一ロット番号で「最初の入庫施設」が異なる在庫が複数存在する場合（例: A→B、C→Bと
  それぞれ横持ちされB病院に同一ロットが複数存在）、自動判定せず一覧表示して担当者に選択させる。
  シリアル管理品(1点物)には本要件は適用されない（重複が発生しないため）。
- **F-6**: 使用報告書の明細部に「入庫先」項目を新設。既存「滅菌期限・管理番号」行の直下に1行追加、
  ラベルは既存項目と同じ全角スペース区切りの書式「入 庫 先：」に統一。値は得意先マスタの施設情報を
  F-4/F-5の判定結果に基づき自動表示。自由入力不可、マスタに該当なしの場合も空欄
  （使用報告自体はブロックしない）。中間履歴ではなく最初の入庫施設のみ表示。

## 使用報告の操作手順（F-5を含む）

1. メニュー「使用報告」→「置き在庫報告」タブ
2. 使用日・施設名等入力→「確認する」
3. 製品入力方法を選択（「リストから選択」or「スキャン」）
4. （F-5該当時のみ）同一ロットで入庫先が異なる在庫が複数あれば「入庫先はどちらですか」選択画面が
   表示される。該当なしなら自動的に次へ進む
5. 使用数量を入力
6. 報告内容確認→「確定する」
7. 完了後、登録共有者へ自動メール送信（使用報告書PDF/Excel添付）

※画面イメージ（リスト選択時は製品カードに入庫先候補を並列表示、スキャン時はボトムシート等）は、
ベンダー(WaT&C)協議時に別途共有。
